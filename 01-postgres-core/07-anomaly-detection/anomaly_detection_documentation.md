# Behavioral Anomaly Detection

## Detection Types

- Off-hours access
- Sensitive table access
- High query volume
- Potential data scraping

## Workflow

1. Logs collected via SIEM
2. Baseline profile applied
3. Anomalies logged
4. Risk score calculated
5. SOC notified if threshold exceeded

## Compliance Impact

Supports continuous verification model.
Detects insider threats and privilege misuse.
