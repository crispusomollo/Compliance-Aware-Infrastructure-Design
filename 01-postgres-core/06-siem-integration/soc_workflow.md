# SOC Incident Workflow

## Alert Lifecycle

1. Alert triggered (SIEM)
2. Tier 1 analyst validation
3. Correlate with change management
4. Escalate to DBA or Security
5. Containment action
6. Evidence preservation
7. Incident documentation
8. Post-incident review

## Severity Levels

- LOW
- MEDIUM
- HIGH
- CRITICAL

## Evidence Preservation

- Logs copied to secure archive
- SHA256 hash generated
- Stored in restricted directory
