# Reference Architecture

## Overview

This lab implements a compliance-aware PostgreSQL environment using:

- Hardened configuration
- RBAC
- Centralized logging
- High availability
- Zero-trust segmentation
- Continuous verification

## Layers

1. Access Layer (Bastion + MFA)
2. Database Layer (PostgreSQL hardened)
3. Availability Layer (Streaming replication)
4. Detection Layer (SIEM simulation)
5. Governance Layer (Change management + compliance scoring)
