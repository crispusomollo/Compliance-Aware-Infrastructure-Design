# Threat Model

## Assets
- Sensitive data (patient_data, payroll)
- Database credentials
- Audit logs
- Backup archives

## Threat Actors
- External attacker
- Insider privileged user
- Compromised service account

## Risk Categories
- Data exfiltration
- Privilege escalation
- Ransomware
- Unauthorized DDL

## Controls Implemented
- Least privilege
- Audit logging
- SIEM monitoring
- Zero-trust enforcement
- Automated compliance scoring
